One line, at most 200 characters, in which a robot vacuum explains why it missed a spot.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt`. Run it with Node 22+.

## The line

> I did not miss the spot. My sensors classified it as load-bearing dust, and demolition is not on my schedule.

109 characters, valid UTF-8, one line — a robot vacuum's deadpan excuse for missing a spot.
